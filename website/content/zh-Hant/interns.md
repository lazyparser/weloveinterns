## 先說清楚這份名單的規則

本頁內容取自儲存庫的 `outstanding-interns.md`：只收錄**有效實習週期超過 3 個月**、且**本人同意或本人提交 PR** 的同學；沒同意的不寫，所以已經畢業工作、但當年沒趕上這個頁面建立的實習生，很多並不在名單上。{{< cite "repo" >}}

類別只有兩種：**LV4+（大能力者 / 超能力者）** 與 **senior interns（高級實習生）**。每條後面的「背書」連結指向甲辰計畫的人才識別互認網路，背書全部在 GitHub 上公開可查。{{< cite "builders-network" >}}

## 他們自己說的話

名單裡最早的兩條（2018–2019 年的機器人時期）保留了實習生寫的原文，比任何總結都好：

> 讀研究所期間，實習為我打開了另一個世界的大門，實習生活很精彩，收穫了豐富的機器人軟體開發技術經驗…… 我也快速地成長成熟，完成了從學生到職員的身分蛻變，感恩這段美好的時光。
> 對後輩實習生的寄語：同學們，讀萬卷書也要行萬里路，一起來實習吧，這裡有不一樣的風景。
> —— 安傳旭（LV5+）

> 實習期間除了一些專業知識的學習，還掌握了更多對以後工作有莫大幫助的技能，比如 git 的使用、團隊協作的流程和規範、程式設計的規範、如何快速檢索知識等等，讓我從一個菜鳥在較短的時間內進步了很多…… 一些同學到現在都是很好的朋友。
> 對後輩實習生的寄語：笨鳥先飛，菜鳥晚歸，好好學習，不懂就問。
> —— 王曉雲（LV4）
