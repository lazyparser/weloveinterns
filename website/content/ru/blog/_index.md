Сейчас записей две: одна — о девяти годах самого репозитория (wiki с заданиями по робототехнике 2017 года → проект «Пятицветный камень» 2026 года), другая — объявление о запуске совместного набора и подготовки, поднятое из старой публикации в аккаунте Проекта Цзячэнь.
