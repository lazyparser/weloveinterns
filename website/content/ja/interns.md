## まず、このリストのルールを

本ページの内容はリポジトリの `outstanding-interns.md` から採っています。載せているのは**有効なインターン期間が 3 か月を超え**、かつ**本人が同意したか本人が PR を出した**学生だけです。同意のない人は書きません。そのため、すでに卒業して働いていて、当時このページの作成に間に合わなかったインターンの多くは、このリストにいません。{{< cite "repo" >}}

区分は二つだけです。**LV4+（大能力者／超能力者）**と **senior interns（シニアインターン）**。各行の後ろの「推薦」リンクは甲辰計画の人材識別相互認証ネットワークを指し、推薦はすべて GitHub 上で公開され、確認できます。{{< cite "builders-network" >}}

## 本人たちの言葉

リストの最初の二件（2018–2019 年のロボット期）は、インターンが書いた原文をそのまま残しています。どんな要約よりも雄弁です：

> 大学院在学中、インターンは私に別の世界の扉を開けてくれました。インターン生活はとても充実していて、ロボットソフトウェア開発の技術経験を豊かに積むことができました…… 私も急速に成長し、学生から社員への立場の転換を果たしました。この素晴らしい時間に感謝しています。
> 後輩のインターンへのメッセージ：皆さん、万巻の書を読むとともに万里の道を行きましょう。一緒にインターンをしませんか。ここには違う景色があります。
> —— 安传旭（LV5+）

> インターン期間中は専門知識の学習のほかに、その後の仕事に大きく役立つ技能も数多く身につけました。たとえば git の使い方、チーム協働の流れと規範、プログラミングの規範、知識をすばやく検索する方法などです。おかげで私は初心者から短い期間で大きく成長できました…… 何人かの仲間は今でもとても良い友人です。
> 後輩のインターンへのメッセージ：できの悪い鳥は先に飛ぶ、新米は遅く帰る。しっかり学び、分からなければ聞くこと。
> —— 王晓云（LV4）
