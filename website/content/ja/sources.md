## 当サイトの内容はどのライセンスで公開しているか

**CC BY-SA 4.0**（表示 — 継承 4.0 国際）。

ここには明確にしておくべき細部があります。口頭ではよく「リポジトリは CC BY」と言われますが、リポジトリの `LICENSE` ファイルは実際には **Attribution-ShareAlike 4.0 International** —— つまり CC BY-SA 4.0 で、「同じ条件で共有」という条項が一つ多いものです。当サイトの本文はこのリポジトリからの改変・抜粋を多く含むため、当サイトも **CC BY-SA 4.0** で公開します（より緩い CC BY 4.0 ではなく）、整合を取っています。当サイトの文章を転用する際は「weloveinterns.org」と表示し、同じライセンスを引き継いでください。{{< cite "repo" >}}

## 素材はどこから来て、どう扱っているか

- **図表はすべて自前で描画**：トップページと五色石ページの「支援体系の閉環図」は当サイトが SVG で描いたもので、構造は CCF 講演の第 44 ページを参照しており、**スクリーンショットも原図の転載もしていません**；
- **第三者の画像も Web フォントも使いません**：favicon は自前の SVG、フォントはシステムフォントスタックです；
- **全文転載はしません**：WeChat 公式アカウントの記事、講演資料、論文はいずれも要点の要約と短い引用にとどめ、原文へのリンクを添えます；
- **データの引用は結論を超えない**：論文と調査は公開要旨にある統計的な結論（定義と時点を含む）だけを引用し、その結論の適用範囲を明記します —— たとえばスタンフォードの論文の著者自身が、結論を「因果推定ではなく記述的な指標」と位置づけています；
- **講演資料の扱い**：二つの講演 PDF は著者本人が当サイトに提供したもので、講演者本人の見解の要約にのみ使用します；
- **人名と推薦**：インターンの項目はリポジトリで「本人が同意したか本人が PR を出した」公開内容のみを採録し、推薦番号は甲辰計画の公開リポジトリへ直接リンクします。
