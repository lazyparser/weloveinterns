このページは別のポジション表ではありません。リポジトリのルートにある `open-internships.md` の「开放岗位列表」節を、そのまま見えるようにしたものです —— 誰かがリポジトリにポジションを一つ足せば、ここには遅かれ早かれカードが一枚増えます。**あるポジションが今も募集中かどうかは、リポジトリを基準にしてください**。このページは、400 行の markdown をスクロールしなくて済むようにするためのものにすぎません。

リストにあるのは現在**募集中**と**定員に達しました**の二つの状態です。定員に達したものは最後に並べてあり、削除はしていません —— 定員に達したからといって、そのポジションがなくなったわけではありません。来年また募集される可能性があります。リポジトリの項目にポジション名だけで、詳細がまだ TBA になっているものは、情報が揃うまでこのページには載せません。

## 応募方法

呉先生 **wuwei@rv2036.org** にメールを送り、次の形式に従ってください：

- 件名は **ポジション番号 - 氏名 - 携帯番号 - 学校**；すでに卒業した方は「学校」を **兼職** に置き換えてください（現在はほぼすべて在校生の身分が求められます）
- 本文には **応募職種に関連する自己紹介** を 300 字以内で書いてください
- **PDF 形式の履歴書を必ず添付してください** —— PDF の履歴書がないメールは返信をお約束できません

書く前に、次の三つの資料を読むことをおすすめします：『极简项目管理』（PLCT と共同養成の管理方法）、『我们如何进行实习生招聘』、『我们如何对实习生进行能力评定和培养』。リンクはすべてリポジトリの同じ節にあります。

## すべてのポジションに共通の要件

- 強い向上心があり、自分をより強く、より良くしたいと考えていること
- 他者と積極的かつ謙虚に働き、チームメンバーのメッセージにすみやかに応答できること

技術職（開発、テスト、ティーチングアシスタント）にはさらに次を求めます：

- 既定で能力レベル **LV2 以上** が必要です（一部のポジションは LV1 まで緩和。各カードを参照）
- Linux のコマンドラインを自在に使い、簡単な Bash スクリプトを書けること；git でチーム協働ができること
- ネットワークの基本を理解していること：SSH の任意ポートログイン、Port Forwarding、リバース接続、ProxyCommand といった設定を自分でこなせること

## 見落とされやすい注意点

- オープンソースコミュニティは**個人のデビュー**であり、すべての行動が公開されます。強い心が必要です
- 最初に結ぶインターン契約は 3 か月で、いつでも参加・退出できます；インターン証明書は契約の発効から実際の退出までを基準とします
- インターン期間の終了後は、メンバー企業と自由に契約更新を協議できます。本インターンはその後のインターン契約を拘束しません
- **「インターン手当なし」のポジションは実在します**：K181–K183 のように主宰者が自ら資金を集めたポジションはインターン手当を出しませんが、RISC-V 開発ボードと Token を提供します；契約とインターン証明書は通常どおりです

能力レベルの評価方法やインターン期間中の査定を先に知りたい方は[共同養成プログラムの回り方](program/)へ；この道を通った人が今どこにいるかを見たい方は[インターン一覧](interns/)へ。
